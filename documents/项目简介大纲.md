# 异智（YiZhi）项目简介大纲

## 0. 文档说明
- 文档目标：用于对外介绍本项目的背景、方案、能力与使用方式。
- 适用对象：评审专家、业务方、开发人员、法律从业者。
- 内容边界：聚焦“类案检索 + 结构化分析 + 报告生成”能力，不展开底层算法细节。

## 1. 项目基础信息
- 项目名称：异智（YiZhi）法律 AI 类案检索系统。
- 项目定位：面向法律实务的工具型 AI 产品（可扩展为智能体系统）。
- 团队与背景：2026 中国外包大赛法律 AI 赛道项目，结合得理开放平台与大模型能力。
- 技术栈总览：FastAPI、Streamlit、Python、LangChain、openpyxl、python-docx。
- 外部能力接入：`deli_api`（封装 `queryListCase`、`queryListLaw`）。
- 当前交付形态：可通过 API/前端触发工作流，输出 Excel 与 Word 文件。

## 2. 项目需求分析
- 行业痛点：关键词检索成本高、人工筛选耗时、结论难结构化复用。
- 目标用户：律师、法官、法务、法律科技团队。
- 核心需求：自然语言输入案情后，快速输出可用的类案检索结果与分析报告。
- 输出需求拆解：
- Excel：类案信息结构化汇总（含“主要原因”“关键裁判结论”）。
- Word：争议焦点、裁判要旨、法律依据、结果分析、附件原文。
- 非功能需求：准确性、可追溯性、可解释性、稳定性、生成效率。

## 3. 解决方案思路
- 整体思路：检索增强 + 结构化抽取 + 模板化生成。
- 端到端流程：
- 步骤1：用户输入检索主题与参数。
- 步骤2：工作流改写查询并召回候选案例。
- 步骤3：大模型提取案由、法院观点、裁判结果、主要原因与结论分类。
- 步骤4：补充法律依据并做统计归纳。
- 步骤5：生成 Excel 检索表与 Word 报告。
- 架构分层：接入层（UI/API）- 编排层（workflow）- 数据接入层（deli_api）- 导出层（excel/word）。
- 设计原则：可扩展、可替换、可追踪、低耦合。

## 4. 关键功能说明
- 功能1：自然语言检索与查询改写（提升召回覆盖与相关性）。
- 功能2：案例去重与字段抽取（统一输出结构）。
- 功能3：关键裁判结论三分类（权利类/金额类/行为类）。
- 功能4：法律依据补全与统计分布分析。
- 功能5：Excel 导出（标准化字段、便于筛选统计）。
- 功能6：Word 报告自动生成（含正文与附件案例原文）。
- 功能7：API 服务化（健康检查、Excel/Word 工作流接口）。
- 功能8：前端交互（可视化触发、预览、下载）。

## 5. 项目使用场景
- 场景1：律师办案前检索同类判例，快速形成诉讼策略草稿。
- 场景2：法官/助理整理类案规则，辅助审理思路归纳。
- 场景3：企业法务评估纠纷风险，形成内部决策参考材料。
- 场景4：法律 AI 团队构建检索与报告自动化能力底座。
- 场景5：教学与研究场景下的案例对比分析与规则提炼。

## 6. AI 工具使用说明（工作流与 Prompt）
- 工作流入口：
- `src/workflow/excel_workflow.py`：生成类案检索 Excel。
- `src/workflow/word_workflow.py`：生成类案检索 Word 报告。
- `src/workflow_api/app.py`：对外暴露工作流 API。
- Prompt 组织：
- 目录：`src/workflow/prompts/excel/`、`src/workflow/prompts/word/`。
- 角色：查询改写、字段抽取、法规查询改写、报告撰写、附件筛选。
- 调用机制：
- 使用结构化输出（Pydantic Schema）约束模型返回格式。
- 通过 `render_prompt` 动态注入 query、样本行、schema 等上下文。
- 运行依赖：
- `.env` 需配置 `DELILEGAL_*` 与 `LLM_*`。
- 前后端可分开启动：FastAPI + Streamlit。
- 使用建议：
- 先做健康检查，再跑 Excel，最后生成 Word 报告。
- 先小样本调试 Prompt，再扩大目标案例数。
