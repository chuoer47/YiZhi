# 类案智裁Agent法律 AI 类案检索系统项目简介

## 1. 项目基础信息

### 1.1 项目名称与定位
类案智裁Agent是面向法律实务场景打造的类案检索与报告生成系统。项目定位为工具型法律 AI 应用，目标是在保持法律专业严谨性的前提下，显著降低类案检索、信息整理与报告撰写的时间成本，并为后续向更复杂的法律智能体系统演进提供稳定底座。

### 1.2 项目背景
类案检索作为法律从业者研判案件、构建诉讼策略的基础工作，更是司法实践统一法律适用、落实类案同判的重要方式。然而，传统法律检索高度依赖执业者的实务经验，检索者需反复调试检索关键词，常出现检索结果冗余繁杂或检索范围不足的情况。即便完成初步检索，后续仍需耗费大量人力完成案例甄别、裁判观点提炼、法律规范梳理与法律文书撰写等工作，整体流程繁琐冗长，且易因信息碎片化造成关键裁判观点与法律依据的遗漏。为适配数字化司法建设与法律服务升级的发展趋势，类案智裁Agent项目聚焦于前述的核心通带，以技术赋能法律实务，构建“自然语言检索 + 结构化抽取 + 文档生成”的一体化工作流，通过将碎片化人工流程转换为可复用、可验证、可持续优化的工程化流程，推动法律服务工作提质增效。

### 1.3 技术栈与系统构成
- 后端服务：FastAPI（对外提供工作流 API）。
- 前端交互：Streamlit（用于检索触发、预览与下载）。
- 核心语言：Python 3.11。
- 大模型能力：LLM API + LangChain（结构化输出由 Pydantic Schema 约束）；当前接入供应商为腾讯混元大模型 API。
- 文档导出：openpyxl（Excel）、python-docx（Word）。
- 检索能力：`deli_api`（封装 `queryListCase` 与 `queryListLaw`）。

### 1.4 当前交付形态
当前系统已经形成可运行的端到端链路，支持通过 API 或前端页面直接触发工作流，自动输出类案检索 Excel 文件与 Word 报告，并返回对应的结果统计和文件路径信息。对于法律团队而言，这意味着从“输入检索主题”到“获取结构化成果”的过程已经具备可直接落地的执行能力。

## 2. 项目需求分析

### 2.1 核心痛点与目标用户
本项目的核心服务对象为法律实务相关从业者，主要涵盖执业律师、司法系统工作人员、企业法务人员与法律科技研发团队等。上述群体均为类案检索的高频使用者，对检索效率、分析精度与成果标准化具有刚性需求。
在司法实务工作中，目标用户普遍面临三大核心痛点。其一，检索精准度不足，关键词匹配依赖个人经验，难以快速定位高匹配度类案，无效信息占用大量工作时间。其二，信息处理效率低下，裁判文书以非结构化文本为主，人工完成案例比对、观点萃取、法条整合的工作强度大，成果难以标准化复用。其三，分析成果转化困难，零散的检索信息无法快速形成体系化论证依据，难以直接支撑文书撰写与法律推演，制约了法律工作的专业效能与产出质量。


### 2.2 功能需求与非功能需求
在功能层面，系统需要支持自然语言交互检索，使用户无需精准提炼专业术语与检索关键词，即可完成候选案例召回、核心字段智能抽取与法律依据补全，并同步生成Excel、Word双格式标准化成果文件。其中“主要原因”与“关键裁判结论（权利类/金额类/行为类）”是业务重点字段；从非功能层面，系统强调结果可读性、过程可追溯性、服务稳定性和生成效率，要求输出不仅“能生成”，还要具备业务可用价值与后续复核基础。

## 3. 解决方案思路

### 3.1 总体方案
类案智裁Agent采用“自然语言检索 + 结构化抽取 + 模板化生成”的实现路径。系统先通过检索接口获取案例与法律数据，再由大模型执行结构化信息提炼，最后将结果装配为标准化文档输出。这样的方案可以兼顾召回覆盖率与成果可用性，适用于类案分析中“既要快、又要准、还要可交付”的典型需求。

### 3.2 端到端流程
完整流程从用户输入检索主题开始，系统先进行查询改写以提升召回质量，再通过案例检索接口逐步抓取并去重样本。随后，工作流对每个样本进行字段抽取和结论分类，并结合法律检索结果生成“法律依据（法律名称+条文）”。在此基础上，系统输出结构化 Excel 结果；若用户继续执行报告工作流，则进一步生成 Word 正文与附件案例内容，形成可直接交付的报告文档。

### 3.3 架构分层
- 接入层：Streamlit UI + FastAPI 接口。
- 编排层：`workflow` 目录下的工作流逻辑与任务组织。
- 数据接入层：`deli_api` 客户端、检索器与工具化封装。
- 导出层：Excel/Word 文档生成模块。

### 3.4 设计原则
本项目在设计上强调低耦合、可扩展和可维护。检索、抽取、导出等模块边界清晰，便于按阶段优化；Prompt 与代码职责分离，便于业务侧迭代；结构化模型约束贯穿主要链路，确保后续统计分析与文档生成具备一致的数据基础。

## 4. 关键功能说明

### 4.1 检索与抽取能力
系统在接收自然语言检索请求后，会生成多条改写查询以扩大召回覆盖，并对召回案例进行去重与结构化抽取。抽取结果不仅包含审理法院、案号、案由、裁判结果等基础字段，还重点生成“法院认为（精简后）”与“主要原因”，用于后续的法律论证与报告撰写。

### 4.2 关键裁判结论分类能力
系统将关键裁判结论拆分为权利类、金额类与行为类三种维度，这一设计能够把传统文本中的复杂裁判信息转化为可比较、可统计的结构化信息。对于诉讼策略分析和风险评估场景，这种分类方式可显著提升结论的可操作性。

### 4.3 法律依据补全与分析能力
系统会结合案件抽取结果生成法律检索查询，并将检索到的法律依据与案例信息联动，形成“法律名称+条文”的结果表达。报告侧会进一步对这些依据做分布性呈现，帮助用户快速建立“事实—规则—结论”的对应关系。

### 4.4 文档自动生成能力
在结果交付层面，系统可自动生成标准化 Excel 检索表和结构化 Word 报告。Excel 更适合筛选统计与团队协作，Word 更适合法律分析展示与正式汇报。两者结合可覆盖“分析过程管理”和“成果表达输出”两个核心环节。

### 4.5 服务化与交互能力
- 后端 API：
- `GET /healthz`：健康检查。
- `POST /api/workflows/excel/run`：触发 Excel 工作流。
- `POST /api/workflows/word/run`：触发 Word 工作流。
- 前端能力：
- 输入检索问题并触发执行。
- 查看统计与预览。
- 下载 Excel/Word 输出文件。

## 5. 项目使用场景
在律师办案场景中，类案智裁Agent可用于诉前检索与裁判规则梳理，帮助快速形成论证框架；在法院辅助场景中，可用于类案归纳与审理思路参考；在企业法务场景中，可用于纠纷风险识别与决策支持；在法律科技研发与教学研究场景中，又可以作为可复用的数据处理与规则提炼基础设施。不同角色的共同收益在于，把重复性的信息处理工作交给系统，把高价值判断留给专业人员。

## 6. AI 工具使用说明（工作流与 Prompt）

### 6.1 工作流入口
- `src/workflow/excel_workflow.py`：生成类案检索 Excel。
- `src/workflow/word_workflow.py`：生成类案检索 Word 报告。
- `src/workflow_api/app.py`：统一对外提供工作流 API。

### 6.2 Prompt 组织方式
- Excel 相关 Prompt：`src/workflow/prompts/excel/`
- Word 相关 Prompt：`src/workflow/prompts/word/`
- 角色覆盖：查询改写、字段抽取、法律查询改写、报告撰写、附件案例筛选。

### 6.3 调用与约束机制
工作流通过 `render_prompt` 动态注入 query、样本、schema 等上下文，并结合 Pydantic 模型约束结构化输出。该机制确保模型输出可以直接进入下游流程，减少自由文本在工程链路中的不确定性。当前实现中，Excel 与 Word 工作流共用核心案例处理链路，在保障复用性的同时降低维护成本。

### 6.4 运行前准备
- `.env` 关键配置：
- `DELILEGAL_APP_ID`
- `DELILEGAL_SECRET`
- `LLM_API_KEY`
- `LLM_BASE_URL`
- `LLM_MODEL`

本项目当前对接腾讯混元大模型 API，配置项沿用统一命名 `LLM_*`，用于保持代码与环境变量字段稳定一致。

### 6.5 推荐使用方式
建议先执行健康检查，再运行 Excel 工作流验证检索与抽取质量，最后生成 Word 报告完成交付。实践中可先用小样本调试 Prompt，再逐步扩大案例数量，以平衡质量、时延与成本。

## 7. 项目价值总结
本项目立足法律实务数字化转型需求，以智能化技术重构类案检索全流程。业务层面，类案智裁Agent有效降低法律检索与案例分析报告撰写的人力成本，统一团队工作标准与输出质量，大幅压缩从法律问题提出到专业成果落地的全流程周期。技术层面，项目已经形成可扩展的法律 AI 工作流范式，实现了检索能力、大语言模型能力与文档生成能力的工程化整合，为适配多案由场景、多文书模板及多角色协同作业筑牢技术基础。后续项目将围绕容错重试、评测体系搭建与自动化测试持续优化迭代，进一步提升系统运行稳定性与长期运维能力，以技术赋能法律实务，实现法律服务工作的提质增效。
